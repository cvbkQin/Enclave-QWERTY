飞地输入法隐私政策

生效日期：2026 年 11 月 6 日 · 版本：5

引言

飞地输入法（英文名 Enclave，以下简称“本应用”）是由个人开发者秦耕耘（以下简称“我们”）开发和提供的中文输入法应用，包含 App 主程序及其附带的键盘扩展。

我们深知个人信息对您的重要性，并依照《中华人民共和国个人信息保护法》等法律法规处理与您相关的信息。本政策说明本应用如何处理信息、您享有哪些权利以及如何联系我们。请您在使用本应用前仔细阅读，特别是以加粗方式标示的内容。

首次打开本应用时，我们会通过弹窗向您展示本政策的要点，您点击“同意”后才会启用 AI 相关功能。您不同意的，仍可使用拼音、英文等基础输入功能。

一、核心原则

  1. 本应用不设账号体系。您的 AI 请求由设备直接发送给您选择的服务商，无第三方中转；我们不收集、不上传您的输入内容。我们的服务器仅用于接收您主动提交的反馈（见第二条第（七）项）和提供可选的词库文件下载。
  2. 打字、候选词计算和输入习惯学习全部在您的设备本地完成。
  3. 只有在您主动使用 AI 功能时，相关文字才会发送到您自己填写的模型服务接口，且不经过我们。

二、各项功能如何处理信息

（一）文字输入

拼音输入、候选词计算、联想预测和输入习惯学习均在您的设备本地完成，不通过网络传输任何内容。

如您主动下载词库文件，本应用会从文件服务器下载：在“键盘 › 词库 › 热门词库”中下载的在线词库（如游戏、网络流行语、百科词库），来自我们的服务器 enclavekb.cn；拼音设置中的“整句模型”，中国大陆店面来自 enclavekb.cn，其他地区来自 GitHub。下载请求不包含您的输入内容；我们的服务器会依法记录访问日志（IP 地址、时间、请求地址、设备标识），保存 6 个月后删除。

您从文件导入的词库（细胞词库 .scel、Rime 词库 .dict.yaml）在您的设备本地读取和转换，不会上传。

（二）AI 润色（按您选的风格改写，例如润色、正式、翻译）

仅在您主动点击润色时（键盘 AI 栏上的“润色”键或固定在 AI 栏上的风格键、识意框回车后出现的“润色”，或帮回卡片上的润色键），本应用会将以下信息直接发送至您为润色配置的模型服务接口（即主接口）：

  1. 要润色的文字：当前输入框中的文字，如您已选中部分文字则仅为所选部分；在帮回卡片上润色时，为卡片上的那条回复；
  2. 您在识意框中写的要求（如有）；
  3. 您所选润色风格的说明文字。

您在识意框中写了内容后点“问答”时，如键盘判断这是对输入框文字的修改要求，也会按本项发送至润色接口。

上述信息由您选择的模型服务提供方依据其服务条款和隐私政策处理，不经过我们的服务器，我们无法访问。在首次发送前，以及您更换接口地址后，本应用会展示信息将发送到的地址，并单独征得您的同意，未经同意不会发送任何内容。

AI 生成内容提示： AI 功能返回的文字由您配置的大模型生成，本应用会在界面上以“AI 生成”“AI改写”“AI问答”等标签提示。生成内容可能不准确，请您自行核对后使用。我们不会在您的正文中插入任何标记。

本应用预设的模型服务仅为方便填写，您可以自由选择其他服务。我们建议您选择依法完成备案的模型服务。

AI 帮回： 仅在您点击“帮回”时（键盘上的“帮回”键，或剪贴板面板里的“帮回”），本应用才读取系统剪贴板（读取时系统会显示“粘贴自…”的提示），并将您复制的那段文字、您选择的帮回风格对应的提示词，以及您填写的回复方向（如有），直接发送至您为润色配置的模型服务接口（即上述主接口），生成几条回复供您挑选；发送前同样适用该接口地址的发送同意。帮回不使用联网搜索。在您点击之前，键盘只通过系统提供的变更标记判断是否有新复制的内容，不读取内容；没有新复制的内容时，点击“帮回”只会打开本机保存的上一次帮回结果，不发送任何内容。读取到的文字会存入剪贴板记录，生成的回复会存入 AI 历史记录，都只保存在本机。别人发给您的消息里可能含有对方的个人信息，请只对您有权处理的内容使用帮回。

（三）识意问答与联网（联网仅在问答接口为千问、Kimi、智谱或腾讯混元时可用）

仅在您主动在键盘里提问时，本应用会将您输入的问题，以及输入框中的文字（如有，选中时仅为选中部分），直接发送至您为识意问答配置的模型服务接口。您可以在“接口”页的“问答”中单独设置识意问答使用的接口（服务商、地址、模型和 API 密钥均由您填写），未单独设置时使用上述主接口。问答接口地址同样会在首次发送前单独征得您的同意。

“识意问答联网”分为“开”“每次询问”“禁止”三档，中国大陆默认“禁止”，其他地区默认“开”，您可以随时在“问答”页更改。中国大陆地区预设的问答服务商均为已完成生成式人工智能服务备案的境内服务商。联网只在识意问答时使用，改写不调用联网搜索。是否需要联网由模型根据问题先行判断；需要联网时，选“开”且已同意过该服务商的会直接联网，选“每次询问”或首次使用该服务商时会先在回答框中征得您的同意，选“禁止”时不会联网，仅提示您可前往开启。各服务商的方式和发送内容如下：

  1. Kimi（北京月之暗面科技有限公司）： 模型判断需要最新信息时，键盘使用您自己填写的 Kimi API 密钥，将您输入的问题本身（原文，不包含输入框中的其他文字、通讯录或其他个人信息）直接发送至 Kimi 的联网搜索接口，再把搜索结果连同问题发给模型生成回答。
  2. 通义千问（阿里云）、智谱 GLM（北京智谱华章科技股份有限公司）、腾讯混元（深圳市腾讯计算机系统有限公司，经腾讯云 TokenHub）： 联网由服务商自带的搜索功能完成。键盘另发一次开启联网的问答请求，其中仅包含您输入的问题本身（不包含输入框中的其他文字、通讯录或其他个人信息），由服务商根据问题生成搜索词、检索公开网页信息并生成回答。

以上请求均使用您自己填写的 API 密钥直接发送给对应服务商，不经过我们的服务器。征得同意时，键盘会提示内容将发送给哪家服务商及收费方式。

联网搜索按次计费，费用由对应服务商从您在该服务商的账户扣除（Kimi、智谱目前约每次 0.01 元，千问按阿里云百炼的价格，腾讯混元按腾讯云 TokenHub 的价格，均以官方价格为准），我们不收取任何费用。

选择“禁止”或在回答框中拒绝联网时，问题只发送给模型本身，不会联网搜索。回答同样以“AI问答”标签提示，内容可能不准确或过时，请您自行核对。

（四）试用与购买

本应用提供 14 天免费试用，试用结束后 AI 功能每天可免费使用一定次数，也可通过 App Store 一次性购买解锁。付款由 Apple 处理，我们不会获得您的付款信息。本应用通过 Apple 提供的接口读取本应用的首次下载日期和购买记录，用于计算试用期和确认是否已购买。

（五）通讯录（可选）

仅在您开启“使用通讯录里的名字”后，键盘通过系统接口读取联系人姓名作为候选词，不读取电话号码等其他信息，也不会上传。您可以随时关闭该开关或在系统设置中撤回通讯录权限。

（六）使用统计

为了在 App 首页向您展示使用情况，本应用按天记录 AI 使用次数、常用词上屏次数等计数，只保存在您的设备上，保留 30 天，不上传。计数不包含您输入的具体内容。

（七）反馈

仅在您在“反馈问题”页面主动填写并点击提交时，本应用会通过加密连接（HTTPS）将以下信息发送至我们位于中国大陆的服务器（enclavekb.cn）：您填写的反馈内容和反馈类型；您选填的联系方式（用于回复您）；您选择附上的截图（最多 3 张）；App 版本、设备型号、系统版本、界面语言和 App Store 地区；以及在您选择附上时，本机的诊断记录（闪退、卡顿记录，不含您输入的文字）。

服务器收到后立即通过邮件服务（腾讯 QQ 邮箱）转发给我们，服务器上不保存反馈内容。为防止滥用，服务器会按 IP 地址限制提交频率，计数仅保存在内存中，24 小时内清除。反馈邮件保存在我们的邮箱中，仅用于处理您的问题和改进本应用，处理完毕后最长保存 12 个月；您可以随时发邮件至 cvbk.qin@gmail.com 要求删除。您的反馈信息将传输至中国境外，由我们使用的 Google 邮箱（Google LLC，美国）接收处理；在中国大陆店面，提交前本应用会以单独勾选的方式征得您的同意，您不勾选的，无法提交反馈。不提交反馈不影响您使用本应用的任何功能。

三、在设备本地存储的信息

以下信息仅保存在您的设备上：

  1. 您填写的模型服务 API 密钥（包括主接口、问答接口及您保存的接口方案），保存在系统钥匙串中；
  2. AI 历史记录（润色、问答和帮回），包括原文与生成结果；
  3. 剪贴板记录：您在键盘中点开剪贴板时读取到的文字，最多 20 条；
  4. 拼音输入学习记录；
  5. 您的提示词、常用词、键盘、接口及语言设置；
  6. 试用开始日期、购买状态、当日 AI 使用次数和按天使用统计；
  7. 您同意本政策的版本和时间。

AI 历史记录仅保存在本机，不会上传。您可以在“历史”页右上角的 ⋯ 菜单中关闭记录、设置保留时长或清空历史；在“设置 › 隐私”中可以清除 AI 历史记录和拼音输入学习记录。

本应用只在您点开键盘上的剪贴板或点击“帮回”时读取系统剪贴板，读取时系统会显示“飞地输入法粘贴自…”的提示；不会在后台读取或监听剪贴板，判断剪贴板是否有新内容时只查看系统提供的变更标记，不读取内容。剪贴板记录仅保存在本机，最多 20 条，超过 24 小时自动删除，不会上传；您可以在剪贴板面板中删除单条记录，在 App 的“键盘”页清除全部剪贴板记录，或关闭“剪贴板记录”开关（关闭时已有记录一并删除）。

卸载本应用后，上述信息将全部从设备上删除（购买记录由 App Store 保存，重新安装后可恢复）。

备份与恢复： 在“设置 › 数据 › 备份与恢复”中，您可以把数据导出为备份文件，或从备份文件恢复。备份文件存放的位置由您在系统文件选择器中选择，例如本机或 iCloud 云盘，由您自行保管和删除。备份文件默认包含您的设置（包括您保存的接口方案，不含密钥）、常用词、提示词和拼音学习记录；AI 历史记录默认不包含，可以勾选。备份文件默认不包含 API 密钥；如您主动勾选，密钥会用您设置的密码加密（PBKDF2 + AES-GCM）后写入备份文件，我们不保存这个密码，也无法帮您找回。剪贴板记录、购买状态和试用信息从不包含在备份文件中：购买可在新设备上通过“恢复购买”找回，试用期不会因恢复备份而重置或延长。导出和恢复都在您的设备上完成，我们的服务器接触不到您的备份。

Enclave Privacy Policy

Effective date: November 6, 2026 · Version 5

Introduction

Enclave (the "App") is provided by Gengyun Qin ("we", "us"). This Privacy Policy explains how information is handled when you use the App and its keyboard extension, and describes your rights.

1. Information We Collect

The App has no user accounts. Your AI requests go straight from your device to the provider you chose, with no third-party relay, and we never collect or upload what you type. Our own server is used only to receive feedback you choose to send (see "Feedback" below) and to offer optional dictionary downloads.

2. How Each Feature Handles Information

Typing

Pinyin input, candidate generation and input learning are performed entirely on your device. No content is transmitted over the network.

If you choose to download a dictionary file, the App downloads it from a file server. Online dictionaries you download under Keyboard › Dictionaries › Popular dictionaries (such as games, internet slang or the encyclopedia dictionary) come from our server enclavekb.cn. The sentence model in the Pinyin settings comes from enclavekb.cn for the mainland China storefront and from GitHub elsewhere. The download request contains nothing you type; our server keeps access logs (IP address, time, requested address, device identifier) for 6 months as required by law, then deletes them.

Dictionaries you import from a file (.scel cell dictionaries or Rime .dict.yaml files) are read and converted on your device and never uploaded.

AI Polish

Only when you tap to polish (the Polish key or a style pinned to the AI bar, Polish after pressing Return in the intent box, or the polish key on a Help Reply card), the App sends the following directly to the model service API you configured for Polish (the main API):

  • the text to polish: the text in the current input field, or only the selected portion if text is selected; when polishing on a Help Reply card, that reply;
  • any instructions you wrote in the intent box;
  • the description of the polish style you chose.

If you write something in the intent box and tap Ask, and the keyboard judges it to be an instruction for changing your text, it is also sent to the Polish API as described here.

This information is processed by the model service provider you have chosen, under that provider's privacy policy. It does not pass through our servers, and we have no access to it.

Before the first transmission, and whenever you change the endpoint address, the App shows you where the text will be sent and asks for your separate consent. Nothing is sent without your consent.

AI-generated content: Text returned by AI features is generated by the model you configured, and the App labels it on screen with tags such as "AI-generated", "AI edit" and "AI Q&A". It may be inaccurate, so please check it before use. We never insert any marker into your text.

AI Help Reply. Only when you tap Help Reply (the Help Reply key on the keyboard, or Help Reply in the clipboard panel), the App reads the system clipboard (the system shows its "pasted from" banner when it does) and sends the text you copied, the prompts for the reply styles you chose, and the reply direction you typed (if any) directly to the model service API you configured for Polish (the main API above), to write a few replies for you to choose from. The consent you gave for that API address applies. Help Reply never uses web search. Before you tap, the keyboard only checks the change marker the system provides to tell whether something new was copied, without reading the contents. If nothing new was copied, tapping Help Reply only reopens your last Help Reply result saved on your device and sends nothing. The text read is saved to your clipboard history and the replies to your AI history, both only on your device. Messages from other people may contain their personal information, so please use Help Reply only on content you are entitled to process.

Ask Answers and Web Search (web search only with a Qwen, Kimi, Zhipu or Tencent Hunyuan answers API)

Only when you actively ask a question in the keyboard, the App sends your question, plus the text in the input field if any (just the selection, if there is one), directly to the model service API you configured for Ask answers. On the API page, under Answers, you can set a separate API for Ask answers (you enter the provider, URL, model and API key); if you don't, the main API above is used. Before the first transmission to an answers API address, the App also asks for your separate consent.

Web search in Ask has three settings: On, Ask each time and Off. It is Off by default in mainland China and On in other regions, and you can change it at any time on the Answers page. In mainland China, the preset answer providers are all domestic providers that have completed generative AI service filing. Web search is used only for answers; rewrites never call web search. The model first decides from the question whether it needs the web. If it does: with On, and once you have agreed for that provider, it searches; with Ask each time, or the first time you use a provider, the keyboard asks for your consent in the answer box first; with Off, nothing is searched and the keyboard only tells you where to turn it on. How each provider searches and what is sent:

  1.
