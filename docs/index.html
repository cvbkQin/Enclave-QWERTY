Enclave keyboard 支持

Enclave 是一款中文拼音输入法，AI 功能使用你自己配置的模型接口。

请先配置你自己的 API
Enclave 不提供 AI 模型，也不附带 API Key。要用 AI 润色，需要先在 App 里填好你自己的模型服务（例如 DeepSeek）和 API Key，否则 AI 功能无法使用。打拼音不需要任何配置。

用 DeepSeek 快速开始

  1. 打开 platform.deepseek.com，注册并登录。
  2. 在“充值”里充一点余额（几元就能用很久）。
  3. 进入“API Keys”，点“创建 API Key”，复制生成的 Key（只显示一次）。
  4. 打开 Enclave App 的“模型接口”，服务商选 DeepSeek，粘贴 API Key，保存。地址 https://api.deepseek.com/v1 和模型 deepseek-chat 会自动填好。

添加键盘

打开 iPhone 的“设置 › 通用 › 键盘 › 键盘 › 添加新键盘”，选择 Enclave。打字时长按或轻点地球键切换到 Enclave。

为什么要“允许完全访问”

不开完全访问也能正常打拼音。只有 AI 润色需要它：用来把你选中的文字发送到你配置的模型接口、按键振动，以及读取和 App 共享的设置。开启方法：设置 › 通用 › 键盘 › 键盘 › Enclave › 允许完全访问。

配置模型接口

打开 Enclave App，进入“模型接口”，选择服务商或“自定义”，填入 API 地址（一般以 /v1 结尾）、模型名和 API Key。支持 OpenAI 兼容格式的接口，也可以连接你自己运行的 Ollama、vLLM、LM Studio 等。API Key 只保存在本机钥匙串。

什么时候会发送文字

只在你点“润色”或“再润”时发送。第一次发送前，以及更换接口地址后，键盘会告诉你要发到哪里并征得你的同意。打字和拼音候选都在手机上完成，不联网。

试用与购买

新安装有 14 天免费试用，AI 功能不限次数。试用结束后每天可免费使用 10 次，也可以在 App 里一次买断，不限次数。打字和拼音永久免费。换手机或重装后，在 App 的购买页点“恢复购买”即可。

润色失败怎么办

先确认已开启完全访问、网络正常；再检查 API 地址、模型名和 API Key 是否正确，以及服务商账户是否有余额。连接局域网里的模型时，手机和电脑需要在同一个网络。

Enclave keyboard Support

Enclave is a Chinese Pinyin keyboard whose AI features use a model API you configure yourself.

You need your own API first
Enclave doesn't include an AI model or an API key. To use AI Polish, add your own model provider (for example DeepSeek) and API key in the app first. Without them, AI features won't work. Pinyin typing needs no setup.

Quick start with DeepSeek

  1. Sign up and log in at platform.deepseek.com.
  2. Add a small amount of credit under Top up.
  3. Open API Keys, create a key and copy it (it is shown only once).
  4. In the Enclave app, open Model API, choose DeepSeek, paste the key and save. The URL https://api.deepseek.com/v1 and model deepseek-chat are filled in for you.

Add the keyboard

Open Settings › General › Keyboard › Keyboards › Add New Keyboard and choose Enclave. Use the globe key to switch to it while typing.

Why Full Access?

Pinyin typing works without Full Access. Only AI Polish needs it: to send your text to the model API you configured, for key haptics, and to read settings shared with the app. To turn it on: Settings › General › Keyboard › Keyboards › Enclave › Allow Full Access.

Set up your model API

In the Enclave app, open the API tab (Model API), pick a provider or Custom, and enter the API URL (usually ending in /v1), model name and API key. Any OpenAI-compatible API works, as do self-hosted servers such as Ollama, vLLM or LM Studio. Your API key is stored only in the iOS Keychain.

When is text sent?

Only when you tap Polish or Rewrite. Before the first send, and after you change the API address, the keyboard shows where the text will go and asks for your consent. Typing and candidates stay on your iPhone.

Trial and purchase

New installs get a 14-day free trial with unlimited AI use. After that, AI features are free 10 times a day, or unlimited with a one-time purchase in the app. Typing and Pinyin are always free. After reinstalling or on a new iPhone, tap Restore Purchases in the app.

Polish failed?

Check that Full Access is on and you are online, then check the API URL, model name and API key, and that your provider account has credit. For a model on your local network, your iPhone and computer must be on the same network.

Enclave keyboard サポート

Enclave は中国語ピンイン入力キーボードです。AI 機能には自分で設定したモデル API を使います。※日本語の入力には対応していません。

まず自分の API を設定してください
Enclave には AI モデルも API キーも含まれていません。AI 機能を使うには、先にアプリで自分のモデルサービス（例：DeepSeek）と API キーを設定する必要があります。設定しないと AI 機能は使えません。ピンイン入力は設定なしで使えます。

DeepSeek ですぐに始める

  1. platform.deepseek.com に登録してログインします。
  2. 「Top up」で少額をチャージします。
  3. 「API Keys」でキーを作成してコピーします（表示は一度だけ）。
  4. Enclave アプリの「モデル API」で DeepSeek を選び、キーを貼り付けて保存します。URL https://api.deepseek.com/v1 とモデル deepseek-chat は自動で入ります。

キーボードを追加する

「設定 › 一般 › キーボード › キーボード › 新しいキーボードを追加」で Enclave を選びます。入力中は地球儀キーで切り替えます。

フルアクセスが必要な理由

フルアクセスがオフでもピンイン入力はできます。必要なのは AI 機能だけで、設定したモデル API への送信、キーの触覚フィードバック、アプリと共有する設定の読み込みに使います。オンにするには「設定 › 一般 › キーボード › キーボード › Enclave › フルアクセスを許可」。

モデル API を設定する

Enclave アプリの「モデル API」でサービスまたは「カスタム」を選び、API の URL（通常 /v1 で終わる）、モデル名、API キーを入力します。OpenAI 互換 API のほか、Ollama・vLLM・LM Studio などのセルフホストにも対応。API キーは端末のキーチェーンにのみ保存されます。

文字が送信されるのはいつ？

「整える」「別の案」をタップしたときだけです。初回と接続先を変えたあとは、送信先を表示して同意を確認します。入力と変換候補は iPhone 内で完結します。

無料体験と購入

新規インストールから 14 日間は AI 機能を回数無制限で無料体験できます。その後は 1 日 10 回まで無料、アプリ内の買い切りで無制限になります。文字入力とピンインはずっと無料です。再インストールや機種変更後は、アプリの「購入を復元」をタップしてください。

うまく動かないとき

フルアクセスとネットワーク接続を確認し、API の URL・モデル名・API キー、サービスの残高を確認してください。ローカルネットワーク上のモデルを使う場合は、iPhone とパソコンを同じネットワークに接続してください。
